# Academic verb guidance

Choose a verb for its meaning, evidence strength, and the conventions of the field. Plain verbs
are often the best choice. Do not replace a natural verb merely to sound academic.

## Use precise verbs when precision helps

| Purpose | Useful verbs | Use with care |
|---|---|---|
| Report evidence | show, indicate, demonstrate, illustrate, report | `demonstrate` can overstate weak evidence |
| Describe methods | use, apply, employ, conduct, measure | name the method when it matters |
| State findings | find, observe, identify, estimate, compare | distinguish an observation from a causal claim |
| Make an argument | argue, propose, suggest, contend | match the verb to the support provided |
| Explain a result | explain, account for, relate to, affect | avoid implying causation without evidence |
| Define scope | include, focus on, examine, address | say what is included or excluded |
| Describe change | increase, reduce, develop, vary, remain | quantify the change when data permits |

## Editing decisions

Keep `show`, `use`, `find`, `help`, `have`, and similar common verbs when they are accurate,
clear, and fit the register. Revise only when the verb hides a needed distinction. For example:

- `The table shows the distribution` is clear when the table directly displays it.
- `The experiment used a control group` is clear when method detail is sufficient.
- `The analysis found a difference` should become `estimated`, `identified`, or `observed` only
  when that word states how the result was obtained or how certain it is.
- `The intervention helped participants` should name the measured outcome if the evidence supports
  a more specific claim.

Avoid inflated substitutions such as `utilize` for `use` or `serves as` for `is`. Prefer a direct
verb unless a more specific one improves the claim.

## Evidence and certainty

| Evidence | Suitable wording |
|---|---|
| Direct, well-supported result | `shows`, `demonstrates`, `is associated with` |
| Observational or mixed evidence | `indicates`, `suggests`, `is consistent with` |
| Proposal or interpretation | `may explain`, `could reflect`, `hypothesizes` |

Read `hedging-guide.md` when certainty is material. This guide offers choices; it does not set a
required vocabulary or a frequency target.
