# Проверить AI-код перед слиянием

Используйте `oma-qa`, чтобы сверить изменение с задуманным поведением. Начните с diff и существующих проверок проекта.

## Загрузите навык

Попросите coding agent выполнить эту команду, затем прочитать возвращённые инструкции и каталог поддержки:

```bash
bunx skills use first-fluke/oh-my-agent@oma-qa
```

## Подготовьте входные данные

- Изменение или локальный ref для сравнения, например `origin/main`.
- Ожидаемое поведение, особенно права, изменения данных и обработку сбоев.
- Существующие команды lint/test и любые ограничения окружения.

## Дайте задачу

```text
Use oma-qa to review this branch's diff against origin/main. Focus on
authorization mistakes, unintended data changes, and regressions in error
handling. Read the affected callers and tests. Keep application source unchanged.
Run the existing focused checks that apply, without installing tools or running
a build. For each confirmed finding, give severity, file:line, the trigger,
observed evidence, and a concrete fix. Report unavailable checks separately.
```

## Проверьте результат

Ожидайте упорядоченные находки с воспроизведением или решающим доказательством в коде, предлагаемое исправление и фактически выполненные команды. Если дефект не подтверждён, отчёт всё равно должен назвать проверенную область и оставшиеся пробелы.

Откройте каждое указанное место и убедитесь, что триггер до него доходит. Повторно выполните узкую проверку, которая послужила доказательством. Отсутствующий инструмент или непроверенный путь — это пробел проверки; одного резюме ревью недостаточно, чтобы считать изменение безопасным для поставки.

## Зависимости и следующий шаг

Агенту нужен доступ к diff, локальным исходникам и существующим инструментам проверки проекта. Проверки браузера, безопасности и производительности требуют соответствующей цели и инструментов. Загрузка навыка эти зависимости не готовит.

При подтверждённом падении продолжите с [отладки падающего теста](https://firstfluke.com/oh-my-agent/docs/tasks/debug-failing-tests/). Если нужны хуки проекта или командные рабочие процессы, [выберите настройку runtime](https://firstfluke.com/oh-my-agent/docs/getting-started/choose-setup/#install-a-skill-preset), которая включает `oma-qa`.
