# Important Defaults

Defaults are selected to make a first project usable while keeping user-owned configuration stable. They are resolved at runtime, so an omitted key can behave differently from an explicit empty value. Start here when the harness works but behaves differently from your expectation.

## Defaults that affect the first run

| Area | Default | Consequence | Override |
|---|---|---|---|
| Response language | `en` | Agent and workflow responses use English unless the project config selects another supported language. An explicit user or session language instruction can still override the project default where the host/workflow supports it. | `language` in `.agents/oma-config.yaml` or `.cue` |
| Model routing | `auto` | The current runtime's native agent configuration is used. Unknown runtimes fall back to `default_cli` when set. | `model_preset`, `default_cli`, or `agents.<id>` |
| Code intelligence | `serena` | A fresh install tries to install Serena and wires its MCP configuration. | `providers.code_intelligence: gortex` or `serena` |
| Code-search guard | `block` | While a code-intelligence provider is configured, a PreToolUse hook denies native `Grep`/`Glob` and recursive shell search (`rg`, `grep -r`, `find -name`) and points the agent at the provider's tools. Prefix a shell command with `OMA_CI_ALLOW_NATIVE=1` when the provider is down. | `providers.code_intelligence_guard: off` |
| Semantic memory | `agentmemory` | Agent Memory is selected for semantic memory when available. | `providers.semantic_memory: honcho` or `none` |
| Web search | `native` | Search uses the runtime's native web channel unless a provider is selected. | `providers.web` |
| Documentation provider | `context7` | Documentation lookup uses the Context7 provider when a skill requests it. | `providers.docs` |
| Telemetry | disabled | OMA writes vendor opt-out settings during linking. | `telemetry: true` |
| CLI auto-update | enabled | The CLI checks for updates unless disabled. | `auto_update_cli: false` |
| Date format | `ISO` | Dates use ISO-style formatting when a project sets no format. | `date_format: US` or `EU` |
| Time zone | system time zone | Scheduled and reported times follow the host when `timezone` is omitted. | `timezone: Australia/Sydney` (or another IANA name) |
| Serena transport | `bridge` | Sessions share one per-project Serena server; an unavailable bridge falls back to session-local stdio. | `serena.mode: stdio` |
| Serena auto-update | enabled | `oma update` upgrades the local Serena tool when possible. | `serena.auto_update: false` |
| Browser DevTools MCP | unset | Existing browser entries are preserved; a fresh interactive install offers `aside`. | `mcp.devtools_browsers: [aside]`, `[chrome]`, `[firefox]`, or `[]` |
| Serena Reaper | scheduled path disabled | `serena_reaper.enabled: false` keeps periodic reaping inactive. Interactive `oma serena reap` still runs. | `serena_reaper.enabled: true` plus `oma serena reaper enable` |

The provider names and defaults come from the runtime loaders and installer prompts. The config file generated by the installer includes comments for the available sections; use those comments as the version-specific schema guide.

## Configuration precedence

OMA searches upward from the current working directory for the nearest `.agents/` directory. It reads `oma-config.cue` when present and falls back to `oma-config.yaml` if shared CUE evaluation fails. A project-local overlay, either `oma-config.local.cue` or `oma-config.local.yaml`, is merged on top; keep only one local overlay. `OMA_MODEL_PRESET` can override `model_preset` for a process. Invalid local configuration stops loading rather than silently selecting another value.

Model routing has two special cases before the fixed-preset order:

- With `model_preset: auto`, the current runtime's native agent/model configuration is used. Explicit `agents.<id>` overrides still take precedence; an unknown runtime can use `default_cli`.
- With `model_preset: free`, child spawns use the local FreeLLMAPI gateway. `free.model` selects the gateway model and replaces per-agent model pins; when it is omitted, `FREELLM_MODEL` or the provider fallback `auto` is used.

For a fixed or custom preset, the effective order is:

1. `agents.<id>` explicit override.
2. The matching `model_preset` entry, built-in or `custom_presets`.
3. The preset's `orchestrator` entry when a role has no entry.
4. `default_cli` as the vendor fallback when the earlier levels do not resolve a plan.

The `free` preset supplies defaults for all three provider settings: `base_url` is `http://127.0.0.1:31415/v1`, `api_key_env` is `FREELLM_API_KEY` (with `FREELLMAPI_API_KEY` accepted as its compatibility alias), and `model` is `auto`. A usable API key in the selected environment variable is still required; there is no vendor fallback. Set these values in `oma-config.local.yaml` when they should stay machine-local, or use `FREELLM_BASE_URL` and `FREELLM_MODEL` for process-level overrides.

## Defaults with surprising consequences

An omitted `mcp.devtools_browsers` key means “leave current browser entries alone.” An explicit empty list removes browser entries during reconciliation. Browser MCP processes run per agent session, so enable them only when a task drives a browser.

The default Serena `bridge` mode reduces duplicate language-server processes when several agents work in one project. `stdio` is the recovery choice when a local bridge cannot start or when strict process isolation matters. Serena self-heals its language-server children on the next tool call; the memory reaper is separate and does not need to be enabled for normal use.

The default telemetry setting is opt-out. Setting `telemetry: true` removes OMA's vendor opt-out entries on the next link/update, which can re-enable vendor features that depend on telemetry. This setting controls vendor integration changes; it does not change the session-cost files OMA writes for its own accounting.

## Recovery paths

| Symptom | Check first | Recovery |
|---|---|---|
| Vendor files are stale | `oma doctor` and `oma link --dry-run` | Run `oma link <vendor>` after editing `.agents/`; preserve the SSOT as the source. |
| A model is not accepted | `oma doctor --profile` | Switch to `auto`, use a built-in preset, or define a model slug under `models:`. |
| Serena tools time out | `oma doctor` and the provider section | Try `serena.mode: stdio`; if memory pressure is the issue, preview with `oma serena reap --dry-run`. |
| A persistent workflow will not stop | `.agents/state/*-state.json` | Say `workflow done`; inspect the state file only when the workflow did not clean up. |
| A scheduled reaper does nothing | `oma doctor` Serena Reaper section | Set `serena_reaper.enabled: true`, then run `oma serena reaper enable`. |
| Local config breaks startup | `oma doctor` error path | Fix or remove the local overlay; do not create both `.cue` and `.yaml` overlays. |
